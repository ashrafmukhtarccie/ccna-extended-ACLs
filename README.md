# ccna-extended-ACLs
This lab focuses on using extended ACLs to control traffic based on source, destination, protocols, and ports.


# Extended ACLs

## Overview

This lab demonstrates how extended ACLs provide detailed control over network traffic.

## Objectives

* Configure extended ACLs
* Filter traffic by source and destination
* Filter protocols and ports
* Apply and verify ACLs

## Tools

* Cisco Packet Tracer
* Cisco IOS

## Outcome

Successfully implemented traffic filtering using extended ACLs.
